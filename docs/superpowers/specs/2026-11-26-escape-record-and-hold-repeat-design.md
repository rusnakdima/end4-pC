# Escape, record bind, and hold-to-repeat — short design

## Intent

Three small fixes requested together:

1. `SUPER+SHIFT+R` must start screen recording. Today it does nothing.
2. Escape must dismiss transient layers and right-click submenus, **and** close top-level overlays including the action center, notification center and start menu. Sidebar-right keeps its current Escape-to-close behavior.
3. Holding the XF86 volume/brightness keys must keep changing the value, not just take one step.

## Constraints

- Never reboot, kill, shut down or restart processes; do not reload/restart the shell or Hyprland. Live state changes must go through watched files.
- The keybind catalog is the frozen source; user changes live in `~/.config/hypr/custom/keybind-overlay.json`. Generated Lua and `state/generated-commands.json` are outputs, regenerated by `scripts/hyprland/generate_keybinds.py`.
- Hyprland 0.57.2: `hl.dsp.exec_cmd()` is a no-op, so commands run through `quickshell:runCommand:<id>` global shortcuts. `release = true` binds never fire. Quickshell 0.3.2 `GlobalShortcut` has `pressed` / `pressed()` / `released()` but no repeat signal, no `enabled` property, and `setName()` is a no-op after registration.
- Session, sleep, poweroff, reload and kill-window binds are never live-tested.

## Approaches and choices

### Record bind

- **A (chosen):** add a real catalog bind `SUPER+SHIFT+R` → `global quickshell:regionRecord`. The shortcut is already registered; only the key is missing. Works without the Wayland socket that the `record.sh` fallback needs.
- B: restore the `record.sh` command from the commented preamble. Rejected: the recorder fails here because there is no Wayland socket, and fixing that needs a process restart.

### Escape

- **1:** transient layers and right-click submenus only. Rejected by the user.
- **2 (chosen):** all top-level overlays too — action center, notification center, start menu, in addition to the transient modes that already handle Escape.
- **3 (chosen in part):** sidebar-right keeps closing on Escape, as it does now.

Existing Escape handling in region selection, ruler, wallpaper picker, Peek, Advanced Paste, polkit, on-screen keyboard, cheatsheet, session screen, overview, window switcher, lock surface, dialogs and context menus stays as-is. Gaps to add: `DesktopMenu.qml`, `StyledOverlayWidget.qml`, `OnScreenDisplay.qml`, `WaffleActionCenter.qml`, `WaffleNotificationCenter.qml`, `WBarAttachedPanelContent.qml`. `StartMenuContent.qml` stops swallowing Escape and closes instead. Settings/Dashboard keep cancel-first behavior (`SettingsEscape.js`): Escape cancels an edit or search first and only then closes, so in-progress edits are not lost.

### Hold-to-repeat

- **A (chosen):** repeat timer in `services/GeneratedCommandShortcuts.qml` for `bind-19`…`bind-22` only. First step runs on press; a timer starts after ~300 ms and ticks ~100 ms while the shortcut stays pressed; it stops on release or whenever `pressed` becomes false. Use the `pressed` property change, not just the signals, so a timer cannot survive a lost release event. No catalog or Lua changes, no reload. Cost: repeat speed is fixed in the shell instead of following the system keyboard repeat rate.
- B: `repeating = true` on the four generated Lua binds. Rejected: depends on the global-shortcut protocol forwarding key repeats, which is unconfirmed, and needs a Hyprland reload.
- C: an evdev listener daemon. Rejected as unnecessary machinery and new permissions.

## Builder notes

- Add the record bind to `defaults/hyprland/keybinds.json`, then regenerate both Lua files and `generated-commands.json`; copy the generated outputs to the live config so the running shell picks them up through its existing file watch.
- Add repeat handling in `GeneratedCommandShortcuts.qml` using the existing `runCommand(id)` guard; do not bypass the id allowlist.
- Keep Escape changes local to each component's existing key handler; do not add a global Escape grab that would bypass per-component priority (edits/search must win).
- Tests: add catalog/generator assertions for the new bind and short-design regression tests for placeholder/duplicate combos; full suite and `validate_keybind_catalog.py` must stay green; live audit must report 0 issues.
