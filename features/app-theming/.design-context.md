# Design context — app theming

## Feature

External GTK and Qt/KDE application windows follow the shell's light/dark mode
and Material You palette. Thunar and Dolphin are the reference apps for MD3
styling. This folder is the self-contained feature bundle (docs, manifest,
CSS templates). The implementation lives in
`scripts/theming/app-theming.sh`; the design record is
`docs/design/app-theming.md`.

## User-visible outcome

Toggle dark mode from the shell → Thunar and Dolphin (and other GTK/Qt apps)
switch in step and use palette-derived colours. Settings → Appearance → App
theming exposes master, toolkit, and per-app switches.

## Constraints

- GTK CSS must never be overwritten wholesale; only a guarded block is managed.
- `gtk-decoration-layout` from `install.sh` must survive every theming run.
- No new dependencies; reuse matugen palette and existing theme tooling.
- Paths resolved relative to the deployed shell directory, not hardcoded.

## Related surfaces

- `modules/common/Config.qml` — `appearance.appTheming` keys.
- `scripts/colors/switchwall.sh` — calls the script on mode changes.
- `scripts/colors/applycolor.sh` — calls `--refresh` on palette changes.
- `modules/ii/settings/DashboardSettingsCatalog.qml` — settings UI.
